# Fractal Search release bundle

Read `README.md` and `AGENT-SETUP.md` before installation, updates or troubleshooting. This directory is a prebuilt application bundle, not a source checkout. Follow the user's authorized scope; never silently substitute providers/models, delete catalogs, restart the desktop shell, or overwrite personal bindings.

For modifications, obtain the matching source revision recorded in `bundle.json` (or the accompanying source snapshot for a dirty-tree candidate), read its root and scoped contributor guidance, validate changes with temporary synthetic data, then package/install the UI and backend together.
